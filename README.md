# High-Performance Computing Course Experiments

This repository contains three completed course experiments:

- **NeRF**: light-weight Lego reconstruction, training logs, checkpoint, and `render_only` results.
- **WRF**: `em_quarter_ss` output and lowest-model-level potential-temperature figures.
- **PRESTO**: repeated runtime measurements for `accelsearch` and `prepdata`.

See [实验结果汇总](实验结果汇总.md) for the concise Chinese summary and figures.
